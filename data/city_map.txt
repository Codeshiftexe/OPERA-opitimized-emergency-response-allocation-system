# ==========================================================================
# OPERA  |  city_map.txt  (road network)
# Read by the C++ loader (src/CityLoader.cpp) at server start.
# Lines starting with # are comments. Fields are separated by spaces.
#
# NODE <id> <x> <y> <name...>
#     id    must be 0, 1, 2, ... in the order the nodes appear (it is the
#           engine's graph id, used everywhere in the API)
#     x, y  position on the web map only; routing never uses them
#
# EDGE <node id> <node id> <minutes>
#     a two-way road; minutes is the travel time and must be 0 or more
#
# Real-world coordinates (needed for live GPS tracking, see LIVE_TRACKING.md):
# GEOREF <lat> <lon> <metres per map unit>
#     at most once. Places EVERY node from its x, y: (x=0, y=0) is at lat/lon,
#     x grows to the east, y to the south.
# GEO <node id> <lat> <lon>
#     exact coordinates of one junction; overrides GEOREF for that node.
#     The crew page (crew.html > "Set up junction coordinates") prints these
#     lines for you while you stand at each junction.
# ==========================================================================
